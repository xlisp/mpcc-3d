# MPCC 彗差改正镜 · 3D 打印件 (mcpp_3d) v2

用 Python 参数化生成 STL, 给 **信达老黑 10 寸牛反 (F5, 焦距约 1270mm)** 自制 MPCC 彗差改正镜的镜筒:
**2" 插入筒进光, M48 (2") 螺纹出光**, 两片镜片的光路、间距和后截距按牧夫天文网 **莴苣** 公布的 DIY 1X MPCC 数据设计。

> 状态: 结构已生成并通过封闭网格检查; **尚未实际打印和上机拍星点验证**。见"风险与待验证"。

---

## 1. 什么是 MPCC / 彗差改正镜

**MPCC = Multi-Purpose Coma Corrector (多用途彗差改正镜)**, 装在牛顿反射镜 (牛反) 调焦座和相机之间的一组小透镜。

- 牛反主镜是**抛物面**, 光轴上的星点完美, 离轴的星会产生**彗差 (coma)**: 星点变成朝视场外侧拖尾的"小彗星", 越靠边越严重。
- 彗差大小与**焦比平方成反比**: 线彗差约 `3·h / (16·N²)` (h 为像高, N 为焦比)。F5 在 APS-C 半对角线 (h≈14mm) 处约 `0.1 mm` 量级, 相当于几十个像素的拖尾; F4 更严重。
- MPCC 在焦点前引入反向彗差抵消它, 让边缘星点恢复圆润。成品 1X MPCC **不改变焦距和焦比**, 并规定一个固定后截距。
- 它不能替代好的准直 (光轴), 也不能校正场曲。

## 3. 本项目镜片与光路

| 镜片 | 直径 | 焦距 | 材质 | 件号 |
|---|---|---|---|---|
| 负透镜 | 27 mm | -185 mm | H-K9 | 356 |
| 平凸透镜 | 41.5 mm | +163 mm | H-K9L | 482 |

光路 (v2 按莴苣数据修正; 用户确认两片镜片与其设计一致, 帖子本身只公开了价格和来源, 规格需网盘资料核对):

```
(主镜来光) -> [2" 插入筒] -> 压圈 -> 负透镜(27) -> 隔圈(5.337mm) -> 平凸镜(41.5, 平面朝负透镜, 凸面朝相机) -> M48 出口 -> 相机
```

核算 (近轴, 忽略镜片厚度): 负透镜在前、平凸镜在后, 间距 7.754mm, 后截距 50.5mm 时焦距缩放系数 ≈ **0.99 (约 1X)**; 若反过来 (平凸镜在前) 约 0.90。这与莴苣所说的"1X MPCC"一致, 也说明 v1 把平凸镜放前面、间距取 10–26mm 是错的。

> **平凸镜朝向是根据帖子数据推断的**: 他用凸面顶点量后截距、且边缘间距小于中心间距, 说明平面朝向负透镜、凸面朝相机。没有看到装配图验证。

## 4. 文件说明

运行 `python3 mpcc.py` (无需第三方库), 在 `stl/` 生成:

| 文件 | 说明 |
|---|---|
| `body.stl` | 主体, 长 38.8mm: 2" 插入筒 (OD 50.4, 长 25, 带顶丝槽) + 45° 锥面法兰 (OD 58) + M48x0.75 外螺纹出口; 内部有 M44x1 内螺纹 (压圈用)、平凸镜座和出光挡肩 |
| `spacer_gap5.34.stl` | 主隔圈: 一侧顶住平凸镜平面, 另一侧是负透镜座, 内锥孔 |
| `spacer_gap4.84.stl` / `spacer_gap5.84.stl` | ±0.5mm 备选隔圈, 用于微调 |
| `ring.stl` | M44x1 压圈, 进光面 4 个缺口 |
| `coupon_m44_int.stl` / `coupon_m48_ext.stl` | 螺纹试配块 |

## 5. 装配步骤

镜片从**进光口 (插入筒端)** 装入, 依次:

1. **平凸镜 (41.5mm)**: 凸面朝出光口, 放到出光端挡肩上 (凸面会从通光孔略探出, 设计上刚好与端面持平)。
2. **隔圈**: 平整端面压在平凸镜的平面上, 负透镜座朝进光口。
3. **负透镜 (27mm)**: 放进隔圈的座里, 凹面朝向平凸镜一侧 (推断, 以实测星点为准)。
4. **压圈**: 拧入压住隔圈外圈, 负透镜只被压圈内圈轻轻罩住 (留约 0.1mm 余量), 不要用力。
5. 建议在镜片和金属/塑料接触处垫薄毛毡; 内壁植绒或消光黑。

---

## 6. 后截距怎么配

设计目标: 平凸镜凸面顶点 → 感光面 = **50.5mm**。

脚本运行后会打印:

```
M48 台阶面(转接环拧到底的位置) -> 感光面 应为 58.6 mm
  = 相机法兰距 17.5 + 延长筒/转接环 41.1 mm
```

- 58.6mm 是从本镜筒 M48 台阶面 (法兰后面那个面, 转接环拧到底的位置) 算起。
- **17.5mm 是帖子里 ASI533 的法兰距示例, 不是你的相机**, 请按你的相机修改 `CAM_FLANGE` 后重新运行。
- 延长筒和转接环的长度要用 M48 垫片微调 (0.2–1.0mm 的薄垫片可以自己打印或购买)。
- 莴苣说 50.5mm 不需要很精确, 偏一点还能调焦, 但会偏离设计状态, 性能略变。

## 7. 关键参数 (`mpcc.py` 顶部)

| 参数 | 默认 | 说明 |
|---|---|---|
| `LA_T` / `LB_T` | 4.0 / 3.0 | **镜片边缘厚度, 估计值, 请用卡尺实测** |
| `GAP_EDGE` / `GAP_CENTER` | 5.337 / 7.754 | 莴苣帖子里的间距 |
| `BACK_FOCUS` | 50.5 | 后截距 |
| `CAM_FLANGE` | 17.5 | 相机法兰距, 示例值 |
| `BARREL_OD` | 50.4 | 调焦座内径 50.8, 留余量 |
| `OUT_MODE` | `"m48"` | 或 `"barrel"` (2" 插入筒出口) |
| `N_GLASS` | 1.5168 | 用于估算凸面矢高 (K9) |
| `RET_CLR`, `M48_MAJOR_D` | 0.3, 47.7 | 螺纹间隙 |

## 8. 打印建议

- 材料: 黑色 PETG / ASA (莴苣用黑色 PLA, 夏天户外建议 PETG/ASA)。
- 层高 0.12–0.16, 外壁 4 层以上。`body` 以插入筒朝下打印, 无需支撑。
- **先打 coupon 试螺纹松紧**, 再打正式件。

## 9. 风险与待验证

1. **镜片规格对应关系未核实**: 帖子里中心与边缘间距之差为 2.42mm, 而本项目的 -185mm 负透镜如果是平凹, 凹面在 r=13.5mm 处矢高仅约 1mm。说明莴苣的镜片组或测量位置可能与你的不完全一致, 或负透镜是别的面型。请对照帖子网盘资料或实测镜片后再定稿 (已多打 ±0.5mm 备选隔圈)。
2. 平凸镜朝向、负透镜凹面朝向来自推断, 未见装配图。
3. 镜片厚度为估计值, 影响镜座位置。
4. 后截距 50.5mm 依赖相机法兰距和延长筒组合, 需要实际配齐。
5. 光学性能没有用光学软件追迹, 仅做过近轴估算; 以实拍星点为准。
6. 该设计会增加边缘渐晕 (莴苣也提到过), F5 + APS-C 属于可接受范围, 更大靶面不建议。
