# MPCC 彗差改正镜 · 3D 打印件 (mcpp_3d)

用 Python 参数化生成 STL, 给 **信达老黑 10 寸牛反 (F5, 焦距约 1270mm)** 自制一个 MPCC 彗差改正镜的镜筒。
手头镜片两片, 镜筒 **2" 插入筒进光, M48 (2") 接口出光**。

> 状态: 结构已生成并通过封闭网格检查; **光学效果尚未验证** (没有做光线追迹, 也没有上机拍星点)。见"风险与待验证"。

---

## 1. 什么是 MPCC / 彗差改正镜

**MPCC = Multi-Purpose Coma Corrector (多用途彗差改正镜)**, 装在牛顿反射镜 (牛反) 的调焦座和相机之间的一组小透镜。

### 为什么牛反需要它
- 牛反的主镜是**抛物面**, 光轴上的星点完美, 但离轴的星会产生**彗差 (coma)**: 星点变成朝向视场外侧的"小彗星"状拖尾, 越靠近视场边缘越严重。
- 彗差大小与**焦比平方成反比**: 线彗差长度约 `3·h / (16·N²)` (h 为像高, N 为焦比)。
  F5 时, 在 APS-C 半对角线 (h≈14mm) 处约 `0.1 mm` 量级, 在常见相机上就是几十个像素的拖尾; F4 更严重, F8 以上才基本可忽略。
- 目视影响不大, 但**深空摄影用大靶面相机**时, 画面四周的星会明显变形, 所以要加彗差镜。

### 它做什么
- 在焦点前放一组正/负透镜, 引入**反向的彗差**抵消抛物面的彗差, 让视场边缘的星点恢复圆润。
- 常见成品 (巴德 MPCC、信达等) 是 **1X** 设计: 不改变焦距和焦比, 只校正彗差, 并规定一个标准**后截距 (常见 55mm)**, 相机端用延长筒/转接环凑够这个距离。
- 它**不能**校正场曲、也不能替代好的光轴 (准直); 光轴不准时彗差镜效果会更差。

## 2. 本项目的镜片与光路

| 镜片 | 直径 | 焦距 | 材质 | 备注 |
|---|---|---|---|---|
| A: 平凸透镜 | 41.5 mm | +163 mm | H-K9L | 件号 482 |
| B: 负透镜 | 27 mm | -185 mm | H-K9 | 件号 356 |

光路 (从进光口到出光口):

```
(主镜来光) -> [2" 插入筒] -> [压圈] -> A 平凸镜 -> [隔圈] -> B 负透镜 -> [M48 出口] -> 相机
```

- 大镜片 A 靠近进光口 (光束较粗), 小镜片 B 靠近出光口 (光束较细)。
- A、B 的**朝向 (凸面朝哪边)** 和**最佳间距**需要光学追迹或实测确定。

## 3. 文件说明

运行 `python3 mpcc.py` (无需第三方库), 在 `stl/` 下生成:

| 文件 | 说明 |
|---|---|
| `body.stl` | 主体: 2" 插入筒 (OD 50.4, 长 30) + 顶丝槽 + 45° 锥面止口法兰 (OD 58) + M48x0.75 外螺纹出口; 内部有 M44x1 内螺纹 (压圈用)、A 镜座、B 镜座和出光孔。总长约 43.8mm |
| `ring.stl` | M44x1 压圈, 进光面有 4 个缺口方便拧 |
| `spacer_10/14/18/22/26.stl` | 不同长度隔圈 (近似 A、B 两镜间距, 单位 mm), 内孔为锥形避免挡光 |
| `coupon_m44_int.stl` | M44 内螺纹试配块, 配 `ring.stl` 试松紧 |
| `coupon_m48_ext.stl` | M48x0.75 外螺纹试配块, 配你的 M48 接口试松紧 |

脚本运行后还会打印**近轴估算表** (不同隔圈长度下的出光后焦距离和焦比缩放系数, 忽略镜片厚度与像差, 仅供参考)。

## 4. 装配步骤

镜片都从**进光口 (插入筒这一端)** 装入:

1. 把 **B 负透镜 (27mm)** 放进出光端的小镜片座。
2. 放入选定长度的**隔圈** (锥孔大口朝进光口)。
3. 放入 **A 平凸镜 (41.5mm)**。
4. 拧入 **压圈**, 轻轻压紧即可, 别用力 (玻璃对塑料)。
5. 建议镜片与压圈、隔圈之间垫薄毛毡/泡棉圈, 防止松动和压裂。
6. 内壁贴植绒纸或喷消光黑, 抑制杂散光。

## 5. 关键参数 (`mpcc.py` 顶部)

| 参数 | 默认 | 说明 |
|---|---|---|
| `LA_T` / `LB_T` | 4.0 / 3.0 | **镜片边缘厚度, 是估计值, 请用卡尺实测后修改** |
| `LENS_CLR` | 0.3 | 镜片座直径余量 |
| `BARREL_OD` | 50.4 | 调焦座内径 50.8, 留打印余量, 按你的调焦座调整 |
| `OUT_MODE` | `"m48"` | `"m48"`: M48x0.75 外螺纹; `"barrel"`: 2" 插入筒出口 |
| `SPACERS` | 10..26 | 要生成的隔圈长度列表 |
| `RET_CLR` | 0.3 | 压圈螺纹间隙 |
| `M48_MAJOR_D` | 47.7 | M48 外螺纹大径 (留间隙) |

改完参数重新运行脚本即可。

## 6. 打印建议

- 材料: 黑色 PETG 或 ASA (夏天车载/户外建议 ASA), 避免 PLA 受热变形。
- 层高 0.12–0.16mm, 外壁 4 层以上, 填充 ≥40%。
- 摆放: `body` 以**插入筒朝下**打印, 无需支撑, 螺纹轴线垂直。
- **先打两个 coupon 试螺纹**, 太松/太紧就调 `RET_CLR`、`M48_MAJOR_D` 后再打正式件。

---

## 7. 调试与使用

1. 先用不同隔圈在实际望远镜上拍星点, 观察视场边缘星点形状, 选出最佳间距。
2. **后截距**: 本镜筒出光口 (M48) 到传感器的距离需要实测, 用延长筒调整到最佳 (成品 1X MPCC 常见 55mm, 本组合因设计不同, 数值要实测)。
3. 先做好**准直** (老黑牛可用 OCAL), 再评估彗差镜效果。

## 8. 风险与待验证

- **光学设计未验证**: 这两片镜片是否能搭成有效的彗差改正组, 取决于面型、朝向、间距和镜片厚度。
- **近轴估算显示本组合更像约 0.8 倍的减焦镜** (焦比缩放系数约 0.74–0.88, 取决于间距和原焦点距离), 与成品"保持 1X"的 MPCC 不同。可能改变视场范围和有效焦比; 彗差是否被校正需要追迹或拍星点才知道。
- 镜片厚度为默认估计值, 影响镜座深度和长度。
- 螺纹 (M44 / M48) 松紧依赖打印机, 必须用试配块校准。

建议后续: 用光学软件 (如 OpticStudio、OSLO 等) 对该组合做追迹, 或直接拍星点实测。
