# MPCC 彗差改正镜 · 3D 打印件 (mcpp_3d) v2

用 Python 参数化生成 STL, 给 **信达老黑 10 寸牛反 (F5, 焦距约 1270mm)** 自制 MPCC 彗差改正镜的镜筒:
**2" 插入筒进光, M48 (2") 螺纹出光**, 两片镜片的光路、间距和后截距按牧夫天文网 **莴苣** 公布的 DIY 1X MPCC 数据设计。

> 状态: 结构已生成并通过封闭网格检查; **尚未实际打印和上机拍星点验证**。见"风险与待验证"。

> 另有 **莴苣原版 P1 (尼康卡口) 的替代件**: ZWO ASI533MC + 1.25" 母口版, 见第 11 节 (`mpcc_p1_zwo.py`)。

---

## 1. 什么是 MPCC / 彗差改正镜

**MPCC = Multi-Purpose Coma Corrector (多用途彗差改正镜)**, 装在牛顿反射镜 (牛反) 调焦座和相机之间的一组小透镜。

- 牛反主镜是**抛物面**, 光轴上的星点完美, 离轴的星会产生**彗差 (coma)**: 星点变成朝视场外侧拖尾的"小彗星", 越靠边越严重。
- 彗差大小与**焦比平方成反比**: 线彗差约 `3·h / (16·N²)` (h 为像高, N 为焦比)。F5 在 APS-C 半对角线 (h≈14mm) 处约 `0.1 mm` 量级, 相当于几十个像素的拖尾; F4 更严重。
- MPCC 在焦点前引入反向彗差抵消它, 让边缘星点恢复圆润。成品 1X MPCC **不改变焦距和焦比**, 并规定一个固定后截距。
- 它不能替代好的准直 (光轴), 也不能校正场曲。

## 3. 本项目镜片与光路

| 镜片 | 直径 | 焦距 | 材质 | 件号 |
|---|---|---|---|---|
| 负透镜 | 27 mm | -185 mm | H-K9 | 356 |
| 平凸透镜 | 41.5 mm | +163 mm | H-K9L | 482 |

光路 (v2 按莴苣数据修正; 用户确认两片镜片与其设计一致, 帖子本身只公开了价格和来源, 规格需网盘资料核对):

```
(主镜来光) -> [2" 插入筒] -> 压圈 -> 负透镜(27) -> 隔圈(5.337mm) -> 平凸镜(41.5, 平面朝负透镜, 凸面朝相机) -> M48 出口 -> 相机
```

核算 (近轴, 忽略镜片厚度): 负透镜在前、平凸镜在后, 间距 7.754mm, 后截距 50.5mm 时焦距缩放系数 ≈ **0.99 (约 1X)**; 若反过来 (平凸镜在前) 约 0.90。这与莴苣所说的"1X MPCC"一致, 也说明 v1 把平凸镜放前面、间距取 10–26mm 是错的。

> **平凸镜朝向是根据帖子数据推断的**: 他用凸面顶点量后截距、且边缘间距小于中心间距, 说明平面朝向负透镜、凸面朝相机。没有看到装配图验证。

## 5. 装配步骤

镜片从**进光口 (插入筒端)** 装入, 依次:

1. **平凸镜 (41.5mm)**: 凸面朝出光口, 放到出光端挡肩上 (凸面会从通光孔略探出, 设计上刚好与端面持平)。
2. **隔圈**: 平整端面压在平凸镜的平面上, 负透镜座朝进光口。
3. **负透镜 (27mm)**: 放进隔圈的座里, 凹面朝向平凸镜一侧 (推断, 以实测星点为准)。
4. **压圈**: 拧入压住隔圈外圈, 负透镜只被压圈内圈轻轻罩住 (留约 0.1mm 余量), 不要用力。
5. 建议在镜片和金属/塑料接触处垫薄毛毡; 内壁植绒或消光黑。

---

## 6. 后截距怎么配

设计目标: 平凸镜凸面顶点 → 感光面 = **50.5mm**。

脚本运行后会打印:

```
M48 台阶面(转接环拧到底的位置) -> 感光面 应为 58.6 mm
  = 相机法兰距 17.5 + 延长筒/转接环 41.1 mm
```

- 58.6mm 是从本镜筒 M48 台阶面 (法兰后面那个面, 转接环拧到底的位置) 算起。
- **17.5mm 是帖子里 ASI533 的法兰距示例, 不是你的相机**, 请按你的相机修改 `CAM_FLANGE` 后重新运行。
- 延长筒和转接环的长度要用 M48 垫片微调 (0.2–1.0mm 的薄垫片可以自己打印或购买)。
- 莴苣说 50.5mm 不需要很精确, 偏一点还能调焦, 但会偏离设计状态, 性能略变。

## 7. 关键参数 (`mpcc.py` 顶部)

| 参数 | 默认 | 说明 |
|---|---|---|
| `LA_T` / `LB_T` | 4.0 / 3.0 | **镜片边缘厚度, 估计值, 请用卡尺实测** |
| `GAP_EDGE` / `GAP_CENTER` | 5.337 / 7.754 | 莴苣帖子里的间距 |
| `BACK_FOCUS` | 50.5 | 后截距 |
| `CAM_FLANGE` | 17.5 | 相机法兰距, 示例值 |
| `BARREL_OD` | 50.4 | 调焦座内径 50.8, 留余量 |
| `OUT_MODE` | `"m48"` | 或 `"barrel"` (2" 插入筒出口) |
| `N_GLASS` | 1.5168 | 用于估算凸面矢高 (K9) |
| `RET_CLR`, `M48_MAJOR_D` | 0.3, 47.7 | 螺纹间隙 |

## 9. 风险与待验证

1. **镜片规格对应关系未核实**: 帖子里中心与边缘间距之差为 2.42mm, 而本项目的 -185mm 负透镜如果是平凹, 凹面在 r=13.5mm 处矢高仅约 1mm。说明莴苣的镜片组或测量位置可能与你的不完全一致, 或负透镜是别的面型。请对照帖子网盘资料或实测镜片后再定稿 (已多打 ±0.5mm 备选隔圈)。
2. 平凸镜朝向、负透镜凹面朝向来自推断, 未见装配图。
3. 镜片厚度为估计值, 影响镜座位置。
4. 后截距 50.5mm 依赖相机法兰距和延长筒组合, 需要实际配齐。
5. 光学性能没有用光学软件追迹, 仅做过近轴估算; 以实拍星点为准。
6. 该设计会增加边缘渐晕 (莴苣也提到过), F5 + APS-C 属于可接受范围, 更大靶面不建议。

## 11. 替代 P1: ZWO ASI533MC + 1.25" 母口版 (`mpcc_p1_zwo.py`)

莴苣的资料包 (`APS-C_MPCC资料/3D打印文件/`) 里, **P1 = 相机侧压盖 + 尼康 F 卡口**。我用 ZWO ASI533MC, 不是尼康单反, 所以只把 P1 换掉:
P2 (2" 镜筒)、P3 (隔圈) 和两片镜片都沿用莴苣的原件, 不用动。

```
(主镜来光) -> P2(2"镜筒) -> 356负透镜 -> P3隔圈 -> 482平凸镜 -> [本件 P1'] -> 1.25"接筒 -> ZWO 相机
```

### 11.1 用法

```bash
cd /Users/xlisp/PyPro/mcpp_3d
python3 mpcc_p1_zwo.py                       # 生成 stl/MPCC_APSC_P1_ZWO125.STL, 并复制到资料目录
python3 mpcc_p1_zwo.py --cam-face-to-sensor 17.5 --socket-d 32.2 --screw-d 3.4 --thread-clr 0.0
```

| 命令行参数 | 默认 | 说明 |
|---|---|---|
| `--cam-face-to-sensor` | 17.5 | 接筒法兰贴合面 → 感光面 (mm)。ZWO 标称 17.5; 相机后面多了延长筒/转接环就改这个 |
| `--socket-d` | 32.2 | 1.25" 母口孔径 (31.75 + 0.45 打印余量), 接筒插不进就加大 |
| `--screw-d` | 3.4 | 顶丝孔径, M4 自攻 |
| `--thread-clr` | 0.0 | 与 P2 配合的螺纹额外半径间隙, 拧不进就加 0.05~0.1 |
| `--no-copy` | - | 不复制 STL 到资料目录 |

脚本也同样是纯 Python、无第三方依赖, 输出二进制 STL (约 78k 三角面, 3.9MB), 运行不到 1 秒, 并自动检查网格是否封闭。

### 11.2 与原版 P1 保持一致的部分 (数值从原版 `MPCC_APSC_P1.STL` 读出)

坐标: z' = 0 在 P1 的螺纹进光端面, 沿光路增加。

| 项目 | 数值 |
|---|---|
| 内螺纹 (与 P2 外螺纹配合) | 螺距 1.0, 牙顶 R23.12 / 牙底 R23.67, 右旋, 梯形牙型 (牙顶平台 0.2 / 牙底平台 0.1 / 牙侧各 0.35) |
| 螺纹终点 | 螺旋牙槽走满 4 圈, 在 θ=0 平面处截止 (z'≈4.375), 之后是 R23.12 光孔, 作为 P2 的螺纹止位 |
| 压镜台阶 | z' = 5.0, 通光孔 R17.7 (Ø35.4); 平凸镜凸面压在这里, 所以镜片光学位置不变 |
| 外径 | Ø50.6, 长 7.8 后用锥面收到母口外径 |

用随机抽样 750 多处 (θ, z') 与原版比较, 螺纹内壁半径偏差平均 0.014mm, 最大 0.054mm。

### 11.3 新增部分

| 项目 | 数值 |
|---|---|
| 总长 (进光端面 → 相机端面) | **39.8 mm** = 感光面位置 57.305 − 17.5 |
| 母口 | Ø32.2 × 深 28 (1.25" = 31.75mm); 底部有 Ø28.5 通光挡肩, 接筒顶在这里 |
| 过渡 | R17.7 压镜孔 → 45° 漏斗 → Ø28.5 挡肩, 内壁在光锥之外, 不挡光 |
| 母口外径 | Ø42, 壁厚约 5 mm |
| 顶丝孔 | 3 个 Ø3.4, 120° 分布 (起始 90°), 距相机端面 7 mm, M4 顶丝 |
| 质量 | 约 24.8 cm³, PLA 约 31 g |

### 11.4 感光面位置怎么推算的

原版 P1 的尼康贴合面在 z = 11.13 (STL 坐标; 进光端面在 z = 0.325), 尼康法兰距 46.5 mm:

```
感光面 z' = (11.13 − 0.325) + 46.5 = 57.305
```

交叉核对 (用镜片参数反算): 平凸镜 f=163, n=1.5168, 凸面曲率半径 R = (n−1)·f ≈ 84.2mm, 压镜接触圆 r=17.7 处矢高 ≈ 1.88mm,
凸面顶点 z' = 5.0 + 1.88 = 6.88, 顶点 → 感光面 = 57.305 − 6.88 = **50.42 mm**, 与莴苣标称的 50.5 mm 相差 0.08 mm, 可以忽略。

本件相机端面 (接筒法兰贴合的圆环面) 放在 z' = 57.305 − 17.5 = 39.8 处, 这样相机装上去感光面就落在设计位置。

### 11.5 装配与打印

- **装配**: 镜片、P3、P2 按莴苣原方案装好, 再把本件 P1' 拧到 P2 的外螺纹上, 压住平凸镜; 相机先装好 1.25" 接筒, 插入母口到法兰贴住端面, 拧紧 3 颗 M4 顶丝。
- **打印**: 母口 (相机端) 朝下平放, 进光螺纹朝上, 不用支撑; 层高 0.12~0.16, 外壁 4 层以上; 黑色 PETG/ASA。
- 内壁建议消光黑处理。顶丝孔太紧时用 3.5mm 钻头过一下。

### 11.6 与第 6 节 (自己设计的 body) 的区别

- 第 6 节的后截距靠 M48 转接环/延长筒凑 50.5mm; 本件直接用"相机端面 → 感光面"一个参数决定长度, 不需要额外垫片。
- 本件保留莴苣原版 P2/P3, 不用 `body.stl` / `ring.stl` / `spacer*.stl`。

### 11.7 待验证 / 风险

1. **17.5mm 是 ZWO 标称的法兰距, 假设 1.25" 接筒法兰面就在这个位置**。如果你的接法多了延长筒或转接环, 要改 `--cam-face-to-sensor`; 装机后可用实际星点和调焦位置确认。
2. 接筒长度要小于母口深度 28mm, 法兰才能贴到端面。
3. 顶丝孔在内外表面共用同一组网格单元, 内壁一侧约 Ø3.4, 向外略微变大, 属于自攻孔近似; 重相机 (ASI533MC Pro 约 410~470g) 建议 3 颗顶丝都拧上。
4. 尚未实际打印, 螺纹和母口的松紧需要试装, 必要时调 `--thread-clr` / `--socket-d`。
5. 若相机接口不是 1.25" 插入式 (例如直接 M42 螺纹), 需要另改相机侧结构。
